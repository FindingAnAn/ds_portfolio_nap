1. Research Problem

Respiratory diseases — COPD, URTI, Bronchitis, Pneumonia — are among the leading causes of global morbidity. Clinical diagnosis typically requires specialist interpretation of auscultation sounds, which is time-consuming and inaccessible in resource-limited settings.

The research question: can a hierarchical, embedded ML system accurately classify 5 respiratory disease categories from audio signals, and can it run efficiently on an FPGA-integrated hardware platform?

Target Classes (5)
  • Healthy
  • COPD
  • URTI (Upper Respiratory Tract Infection)
  • Bronchitis
  • Pneumonia
Key Constraints
  • Must run on embedded FPGA hardware
  • Clinically interpretable features
  • Multi-layer hierarchical architecture
  • High accuracy across all 5 classes

2. Hierarchical 3-Layer Architecture

The system uses a hierarchical classification strategy across three layers, each operating at a different temporal granularity. This mirrors clinical reasoning — from coarse whole-recording patterns down to fine-grained frame-level acoustic events.

Layer 1 Recording Patient-level features over the full audio recording
Layer 2 Non-overlapping frames 20ms frames — statistical descriptors per segment
Layer 3 Overlapping frames 35ms frames, 50% overlap — fine-grained acoustic events
Fusion Score aggregation Layer outputs combined for final decision
Output Disease class One of 5 disease labels per patient

3. My Contribution — Layer 1: Recording-Level Features

I was responsible for computing recording-level (patient-level) features from pre-extracted signal data. These features capture global acoustic properties of a full respiratory recording and form the foundation of Layer 1 classification.

These features were computed per patient from pre-extracted signal data using Python (NumPy, Pandas). The resulting tabular feature vectors were used as input to the Layer 1 Random Forest classifier.

4. My Contribution — Layers 2 & 3: Frame-Level Features

I also contributed to frame-level feature computation at two temporal resolutions, capturing short-time acoustic properties that distinguish breathing patterns across disease classes.

Layer 2 — 20ms frames (non-overlapping)
  • ZCR — Zero Crossing Rate per frame
  • Mean — average amplitude per frame
  • Std — standard deviation
  • Skewness — asymmetry of distribution
  • Kurtosis — tail heaviness of distribution
Layer 3 — 35ms frames (50% overlap)
  • ZCR — Zero Crossing Rate per frame
  • Mean — average amplitude per frame
  • Std — standard deviation
  • Skewness — asymmetry of distribution
  • Kurtosis — tail heaviness of distribution

The 50% overlap in Layer 3 provides higher temporal resolution and captures transient acoustic events (e.g., crackles, wheezes) that are diagnostically significant for distinguishing Pneumonia and Bronchitis from URTI and Healthy classes.

7. Key Learnings

  • Hierarchical classifiers outperform flat multi-class classifiers when class confusion is structured (e.g., URTI vs Healthy are easy to separate, but Bronchitis vs Pneumonia are not).
  • Temporal granularity matters — features extracted at different frame lengths capture complementary acoustic information. The 50% overlap in Layer 3 was critical for capturing transient breathing events.
  • Tabular features for audio can be highly competitive with deep learning approaches when the feature engineering is domain-informed — RMSE, ZCR, and statistical descriptors encoded clinically meaningful signal properties.
  • Embedded constraints drive feature design — every feature had to be computationally lightweight enough to run on the FPGA platform, which shaped the choice of statistical features over spectrograms or MFCC sequences.
